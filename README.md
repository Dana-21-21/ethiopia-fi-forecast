# Ethiopia Financial Inclusion Forecasting System

## Project Overview

This project was developed as part of the Week 11 Data Science Challenge.

The objective is to analyze Ethiopia's financial inclusion ecosystem, evaluate how major national events influence financial inclusion indicators, and forecast future financial inclusion trends for 2025–2027.

The project follows the World Bank Global Findex framework, focusing on two key dimensions:

- Access (Account Ownership)
- Usage (Digital Payment Adoption)
